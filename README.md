# Geographic distribution and body size variation in Drosophila elegans and Drosophila gunungcola

This repository contains the datasets and R scripts used for the statistical analyses and figures presented in our study of the geographic distribution and body size variation of *Drosophila elegans* and *D. gunungcola*.

## Data files

The `data` folder contains two CSV files:

| File | Description | Figures and tables |
|---|---|---|
| `distribution_data.csv` | Geographic distribution and sampling-site data | Figures 2 and S1; Tables 1 and 2 |
| `fly_bodysize.csv` | Body size measurements | Figures 3, 4, and S3–S5; Tables S4 and S5 |

## R scripts

The `scripts` folder contains separate R scripts for the analyses and figures presented in the manuscript.

Each script is labeled with its corresponding figure or table and indicates which dataset is required.

## How to use

1. Download or clone the repository.
2. Open R or RStudio and set the working directory to the main repository folder.
3. Install the R packages required by the scripts.
4. Run the relevant R script using the corresponding dataset from the `data` folder.

## Software

All statistical analyses were performed using R version 4.4.0.
